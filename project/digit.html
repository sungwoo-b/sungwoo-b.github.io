Handwritten Digit Classification

Exploration of Feature Extraction

Computer Vision
Introducing a feature extraction method and evaluating its efficiency and effectiveness
Author

Sung Woo Bak

Published

December 11, 2023

Keywords

Image Classification, Singular Value Decomposition, Rank-k Approximation

There are limitations when handling large-scale datasets. Image data is particularly challenging because a single image contains a large amount of information. The objective of this project is to process such data, classfy images, and evaluate its performance.

One way to handle data efficiently is to extract features and reduce dimensionality. This project uses Singular Value Decomposition (SVD) to extract features and Rank-k Approximation to classify images, while examining its efficiency and accuracy.

Feature Extraction and Classification

In this project, Rank-k Approximation via Singular Value Decomposition (SVD) is used for classification method. This method extracts essential features and reduces dimensionality, improving efficiency. The Singular Value Decomposition is as follows.

\[ \text{Image Data} = U_k \Sigma_k V_k^T \]

This approach extracts essential information from the data, allowing each digit image to be represented in a reduced form. The focus is on the first k left singular vectors U, which capture the important features of the images. The k-th approximation is a linear combination of the vectors \(u_1, u_2, \dots, u_k\), representing one element in their span.

\[ A_k = \sum_{i=1}^{k} \alpha_i u_i \]

The error between test images and the k-approximation is calculated using the Euclidean Norm, which measures the difference or distance between two data. The error is computed as

\[ \text{Error} = \| \text{Test Data Set} - \text{k-Approximation} \|_2 \]

The classification method predicts the digit by finding the smallest error, indicating the closest match between the test image and the k-approximation.

The goal is to find the optimal k that captures most of the data while keeping k as small as possible.

특성 추출과 분류 (Feature Extraction and Classification)

이 프로젝트에서는 Singular Value Decomposition (SVD)을 사용하여 특성을 추출하였고 Rank-k Approximation을 사용하여 이미지를 분류했습니다. 아 방법은 중요한 특성을 추출하여 데이터의 차원을 축소하고 효율성을 향상시킵니다.

Singular Value Decomposition은 다음과 같습니다.

\[ \text{Image Data} = U_k \Sigma_k V_k^T \]

이 접근방식은 데이터의 핵심 정보를 추출하여 각 숫자 이미지를 저차원 형태로 표현할 수 있도록 합니다. 특히 이미지의 많은 특성을 포함하고 있는 첫번째 k개의 Singular 벡터인 u를 중점에 두고 이를 활용하여 분류를 진행했습니다. Rank-k Approximation은 \(u_1, u_2, \dots, u_k\)들의 선형 결합이고 이들의 부분 공간 (Span) 중 하나입니다.

\[ A_k = \sum_{i=1}^{k} \alpha_i u_i \]

훈련용 이미지들을 사용하여 위와 같은 방법으로 k-Approximation을 구하고 검증용 이미지와의 오차 혹은 거리를 Euclidean Norm을 이용하여 계산합니다. 오차는 다음과 같습니다.

\[ \text{Error} = \| \text{Test Data Set} - \text{k-Approximation} \|_2 \]

분류 방법은 오차가 가장 작은 값을 찾아 숫자를 분류하며 이는 테스트 이미지와 k-Approximation 사이에서 가장 근접한 매칭을 의미합니다.

마지막으로는 데이터의 대부분을 포함하면서 가능한 가장 작은 최적의 k를 찾는 것입니다.
